# Правила расчёта

## Модули

- `full` — полностью внутри рабочего контура
- `cut` — частичное пересечение → **1 модуль к покупке**
- Остатки не переиспользуются

## Запас

По умолчанию 5%:

```
modulesWithWasteCount = ceil(totalModulesCount × (1 + wastePercent / 100))
```

## Площадь покупки

```
purchaseAreaSqm = modulesWithWasteCount × moduleWidth × moduleLength / 1_000_000
```

## Стоимость

| priceUnit | Формула |
|---|---|
| `piece` | `modulesWithWasteCount × price` |
| `sqm` | `purchaseAreaSqm × price` |
| `unknown` | не рассчитывается, предупреждение |

## Вес

```
totalWeightKg = modulesWithWasteCount × weightKg
```

Только если вес одного модуля достоверно известен.

## Технологический зазор

По умолчанию 5 мм. Реализован как внутренний offset контура, не как уменьшение площади по формуле.

## Окантовка (канты)

Доступна только для серии **Optima Duos** (`optima-duos`); для остальных серий настройка скрыта,
а `CalculationResult.edging` отсутствует.

### Элементы

| Элемент | Габарит | Занимает вдоль края поля |
|---|---|---|
| Прямой №1 / №2 | толщина × 45 × 250 мм | 250 мм |
| Угловой №1–№4 | толщина × 45 × 125 × 125 мм | по 125 мм на каждой из двух сторон |

Толщина канта (9 или 16 мм) выбирается вручную и должна совпадать с толщиной плитки;
при расхождении панель показывает предупреждение.

### Место в помещении

Кант занимает свои 45 мм внутри помещения, поэтому зона укладки сжимается дополнительно:

```
workingInset = gapMm + (edging.enabled ? 45 : 0)
```

Правило живёт в `workingInsetMm()` (`shared/geometry/edging.ts`) — единый источник для store и расчёта.
Включение канта уменьшает число плиток; это и есть «расчёт с учётом и без учёта окантовки».

### Подбор элементов

Кант строится по периметру зоны укладки, по всему контуру независимо от формы помещения.
Проёмы на него не влияют.

- **Внешний угол 90°** → угловой элемент, забирает по 125 мм с каждой примыкающей стороны
- **Внутренний (вогнутый) угол** → углового элемента нет, прямые канты стыкуются подрезкой по месту
- **Угол не 90°** → элемент не подбирается, предупреждение `edging_unsupported_corner`

Число прямых на стороне: `ceil((длина стороны − отступы углов) / 250)`.
Последний элемент на стороне при необходимости режется → `edging_trimmed_pieces`.

### Тип элемента

У плитки Optima Duos «гвоздики» на двух смежных сторонах и «дырочки» на двух других,
поэтому тип канта задаётся направлением внешней нормали стороны поля:

| Сторона поля | Прямой кант |
|---|---|
| верх, лево | №2 |
| низ, право | №1 |

Угловой элемент определяется парой сторон: верх+лево → №4, верх+право → №2,
низ+право → №3, низ+лево → №1. Соответствует схеме крепления производителя.

### Стоимость

Цена зависит от цвета выбранной плитки, не от толщины канта:

| | Прямой | Угловой |
|---|---|---|
| Чёрный | 66 ₽/шт | 136 ₽/шт |
| Цветной | 74 ₽/шт | 148 ₽/шт |

Чёрный определяется по названию цвета плитки (`Черный`, `Чёрный`, `black`). Остальные цвета — цветной кант.

```
totalCost = straightTotal × ценаПрямого + cornerTotal × ценаУглового
```

Цены заданы в `EDGING_PRICES`. Итог по заказу считает `totalOrderCost()`: покрытие + окантовка.
