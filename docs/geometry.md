# Геометрия

Все расчёты в **миллиметрах**. Canvas масштабируется отдельно (zoom/pan).

## Модули

- `polygon.ts` — площадь, самопересечение, offset, шаблоны комнат
- `layout.ts` — сетка модулей, clipping через `martinez-polygon-clipping`
- `edging.ts` — раскладка окантовки по периметру зоны укладки

## Классификация модулей

Пересечение прямоугольника модуля с рабочим polygon:
- площадь пересечения ≈ площадь модуля → `full`
- площадь > 0 → `cut`
- иначе → `outside` (не отображается)

## Offset

Параллельный сдвиг рёбер внутрь с пересечением линий. При неудаче — сообщение пользователю.

## Шаблоны

- Прямоугольник
- Г-образная
- П-образная
- С нишей

## Окантовка

`generateEdging(fieldPolygon)` обходит периметр зоны укладки и возвращает готовые полигоны
элементов вместе с их количеством по типам. Ориентация контура определяется знаковой площадью,
внешняя нормаль ребра — поворотом его направления. Выпуклость вершины даётся векторным
произведением направлений смежных рёбер: угловой элемент ставится только во внешний угол 90°.

Правила подбора типов и стоимости — в [calculation-rules.md](calculation-rules.md).

## Оптимизация

`optimizeLayout()` перебирает смещения X/Y в пределах размера модуля, минимизируя количество подрезок.
