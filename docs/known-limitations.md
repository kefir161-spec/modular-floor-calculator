# Известные ограничения

1. **Единица цены** — в XML не указана; итоговая стоимость не рассчитывается
2. **Артикул** — отсутствует в фиде; показывается только технический offer id
3. **Упаковки** — округление до упаковки не реализовано
4. **Обрезки** — повторное использование остатков не поддерживается
5. **Диагональная раскладка** — не реализована
6. **Игровые коврики** — исключены до решения заказчика
7. **Offset** — на очень сложных контурах может не построиться
8. **Автосохранение** — сохраняется при ручном сохранении; полный autosave на каждое изменение не включён
9. **Изображения в PDF** — зависят от CORS политики plastfactor.com
10. **Шестиугольные модули (Sensor Sota)** — раскладка прямоугольная, на схеме
    показывается вписанный в шестиугольник фрагмент фактуры
11. **Фото отдельных SKU с засветом** — у белого Canal (5463) глянец засвечен:
    вместо фактуры показывается ровная поверхность цвета плитки
    (см. docs/layout-textures.md)
12. **Канты в невыпрямоугольных углах** — угловой элемент рассчитан на 90°; во внутренних углах
    и в углах другой величины прямые канты подрезаются по месту, элемент не подбирается
13. **Канты только у Optima Duos** — окантовка других серий в фиде отсутствует
14. **Кратность стороны 250 мм** — если сторона поля не кратна 250 мм, последний прямой кант
    режется; расчёт учитывает его как целый элемент к покупке

## Удалено в Фазе 0

- `optimizeLayout` — мёртвый код, медленный перебор; при необходимости — отдельная задача
- `showGrid` — флаг хранился, но сетка не рисовалась; отбрасывается при миграции проектов
- `useIsMobile` — неиспользуемый хелпер без подписки на media query
