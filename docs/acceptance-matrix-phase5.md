## Визуальные правила Фазы 5

- Карточки панелей — border, без одинаковых тяжёлых теней.
- Тени только у floating (toolbar, sticky, toast, drawer).
- Warning/error для текста — затемнённые токены (не pastel).
- Синий brand не заливает фоны панелей.
